## 🎙️ Sobre o projeto

O **Vocalis** é um produto fictício voltado ao aprendizado de canto e música para pessoas iniciantes. A proposta é apresentar os fundamentos da prática vocal e da musicalidade de forma acolhedora, gradual e acessível, inclusive para quem não possui experiência anterior.

Este projeto consiste no desenvolvimento de uma **landing page responsiva** para apresentar a proposta do produto, seus benefícios, módulos demonstrativos e uma oferta introdutória fictícia.

Desenvolvido como atividade acadêmica da disciplina de **Desenvolvimento Front-end**, o projeto tem como foco a aplicação dos conhecimentos estudados em React, CSS Modules, organização de componentes, arquitetura de software e desenvolvimento de interfaces.

## 🎯 Objetivos

- Criar uma identidade visual coerente com a proposta do Vocalis.
- Apresentar o produto de maneira clara e atrativa.
- Organizar as informações em seções de uma landing page.
- Implementar interações simples e funcionais.
- Aplicar os conhecimentos de React e CSS Modules estudados em aula.
- Desenvolver uma interface responsiva e de fácil navegação.
- Organizar o código de acordo com a arquitetura escolhida.
- Documentar o processo de desenvolvimento e as decisões do projeto.

## 🎵 Proposta e público-alvo

O Vocalis foi pensado para pessoas que desejam iniciar seus estudos de canto e música, mesmo sem experiência anterior.

A comunicação visual e textual busca transmitir **acolhimento, descoberta e liberdade de expressão**, evitando uma abordagem excessivamente técnica ou intimidadora.

> *Sua voz. Seu ritmo. Sua descoberta.*

Foi escolhida a arquitetura **MVVM (Model-View-ViewModel)** para orientar a organização do projeto. A escolha considera a dimensão e a complexidade da landing page, buscando manter o código organizado sem introduzir uma estrutura de pastas e abstrações desnecessárias para a solução.


## 🗺️ Jornada de construção

### 💡 Ideia inicial

A ideia do Vocalis surgiu do interesse em criar um produto voltado ao aprendizado de canto. Ao observar anúncios de aplicativos e plataformas de aprendizagem musical, percebi que encontrava com mais frequência soluções voltadas a outros instrumentos e poucas propostas relacionadas especificamente ao canto, uma área que desperta meu interesse.

Essa percepção serviu como ponto de partida para imaginar uma plataforma de aprendizagem vocal acessível a pessoas iniciantes.

### 🔎 Pesquisa e referências

Durante a pesquisa, foram consideradas plataformas de aprendizagem musical que utilizam recursos digitais para ensinar música de forma acessível e gradual.

**Referências consultadas:**

- [Simply Piano](https://www.hellosimply.com/simply-piano) — referência de uma plataforma de aprendizagem musical voltada ao ensino de piano.
- [Yousician](https://yousician.com/) — referência de uma plataforma de aprendizagem musical que oferece experiências de estudo de instrumentos e canto.

Essas plataformas foram utilizadas como referências para compreender como produtos digitais de aprendizagem musical apresentam suas propostas e organizam a comunicação com o público.

A intenção não foi reproduzir suas interfaces, mas observar o contexto de soluções existentes e utilizá-lo como ponto de partida para desenvolver uma proposta própria, direcionada à aprendizagem vocal.

### 🧪 Evolução da solução

O desenvolvimento passou por diferentes etapas: definição da ideia, elaboração da especificação funcional e visual, geração da proposta no Figma Make e continuidade da implementação a partir do código exportado.

A especificação foi utilizada como orientação para a criação da página. O Figma Make gerou uma proposta visual que ficou próxima do resultado desejado, e a interação com a ferramenta permitiu realizar ajustes até chegar a uma versão adequada às expectativas iniciais.

Depois da etapa visual, o código foi exportado para dar continuidade ao desenvolvimento. O OpenCode foi utilizado como apoio à organização arquitetural, aos ajustes no código e à correção de funcionalidades que não estavam funcionando como esperado.

**Principais decisões do processo:**

- **Estrutura da página:** utilização da especificação para orientar a organização das seções e dos conteúdos.
- **Identidade visual:** aproveitamento da proposta do Figma Make como referência para a interface.
- **Organização arquitetural:** escolha do padrão MVVM para orientar a estrutura do projeto.
- **Ajustes funcionais:** utilização do OpenCode como apoio à investigação e à correção de problemas na implementação.

### 🏁 Resultado final

O Vocalis foi concebido como uma landing page para apresentar um produto fictício de aprendizagem vocal, reunindo informações sobre sua proposta, seus benefícios e seus recursos em uma interface visualmente coerente.

A proposta gerada no Figma Make ficou próxima das expectativas iniciais e serviu como referência para a continuidade do desenvolvimento. O projeto também permitiu trabalhar com especificação funcional e visual, componentes React, CSS Modules, organização arquitetural e ferramentas de inteligência artificial como apoio ao processo.

**O que poderia ser melhorado com mais tempo?**

- Pesquisar e selecionar imagens que reforcem a identidade visual e a proposta musical.
- Explorar novas possibilidades de design e aprimorar os detalhes visuais da interface.
- Desenvolver páginas adicionais para aprofundar a experiência de navegação.
- Ampliar as funcionalidades para explorar melhor a separação de responsabilidades proposta pelo MVVM.


Essas melhorias permitiriam aprofundar tanto a experiência do usuário quanto a aplicação dos conhecimentos técnicos estudados.

## 🚀 Como executar o projeto

Na pasta do projeto que contém o arquivo `package.json`, execute os seguintes comandos no terminal:

```bash
npm install
npm run dev
```

- `npm install`: instala as dependências declaradas no projeto.
- `npm run dev`: inicia o servidor de desenvolvimento, desde que o script `dev` esteja configurado no `package.json`.

Em seguida, acesse no navegador o endereço local informado pelo terminal.
